How to read this page
  • "Known on" a date shows a number exactly as it had been published by that date, before any later revisions. This is what a report or model built on that day would have used.
  • Yellow rows are numbers that changed between the two dates you pick. Each one says what happened and what it means for you.
  • Old numbers are never deleted. Every number links to the SEC filing it came from.

Glossary
Revised by the company (restatement)
The company published a different value for a period it had already reported, for example to correct an error or apply a new accounting rule.
Stock split
The company split each share into several (e.g. 4-for-1). Per-share numbers like EPS are restated so all years use the same number of shares. The business itself did not change.
Corrected by our data team
A number changed in the data source without a new filing to explain it. We hold such changes back until a person has checked them.
Annual report (10-K), quarterly report (10-Q)
The official financial reports US-listed companies file with the SEC.
Diluted EPS
Earnings per share, counting shares that could be created from options and convertible securities.
Alternative data
Information from outside company reports, here GitHub developer activity. It counts only from the day we collected it: history collected later cannot be used to judge what we knew at the time.
Calculated Q4
Companies rarely report the fourth quarter on its own, so we calculate it as the full year minus the first three quarters. This is not done for per-share numbers, where it would be wrong.
